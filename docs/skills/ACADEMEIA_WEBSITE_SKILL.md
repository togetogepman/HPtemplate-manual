# Academeia Website Skill

## 対象

株式会社アカデメイア公式サイト、特に AkaiKKR 関連ページや製品紹介ページ。

## 課題

一部ページは、WordPress本文ではなく、サーバー上のスクリプトを介して表示されている可能性がある。
この構造は、本文修正のたびにサーバーファイル編集が必要になり、編集・保守を複雑にする。

## 改修方針

- 外部JSやサーバースクリプトによるHTML生成を減らす。
- 可能な限りWordPress固定ページ内で編集できる構造に戻す。
- CSSは分離してよいが、本文構造はWordPress管理画面から追えるようにする。
- 繰り返し要素は、ブロックパターン、再利用ブロック、最小限のショートコードで扱う。
- HTML直打ちが必要な場合でも、構造を単純に保つ。
- 動的生成が必要な箇所と、静的本文で十分な箇所を分ける。

## 禁止

- 編集者がサーバーファイルを触らないと本文修正できない構造を増やさない。
- 表示生成ロジックを複雑化しない。
- WordPress側とサーバースクリプト側に同じ情報を二重管理しない。
- デザイン調整のためだけに本文構造を読みにくくしない。

## 優先順位

1. 編集しやすさ
2. 保守しやすさ
3. 表示の安定性
4. デザイン
5. 高度な動的機能

## 実装時の注意

- 既存HTML/CSS/JSの役割を読んでから変更する。
- 置き換え対象を一気に全削除しない。
- まず小さなセクション単位で、WordPress本文化できるか検討する。
- 表示崩れが起きやすいので、PC幅とスマホ幅の両方を確認する。
