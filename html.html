HTML Guide

HTMLを編集する

HTMLを直接編集する人に向けて、文字や画像を安全に変更するための基本手順を案内します。

編集するファイル

実際に編集するファイルはindex.htmlです。sample.htmlは完成見本なので、通常は編集しません。

タグやclassを不用意に削除すると表示が崩れます。基本的には、このページで案内する文字や画像のファイル名だけを変更してください。

このページの内容

  1. 編集前の準備
  2. 文字を変更する
  3. 画像を変更する
  4. 各セクションを編集する
  5. ブラウザで確認する

01

編集前の準備

編集するリポジトリとファイルを間違えないように準備します。

  1. GitHub Desktopを開き、編集する自分のリポジトリを選びます。

  2. メニューのShow in Explorerから、リポジトリの保存フォルダを開きます。OSによって表示名が異なる場合があります。

  3. Visual Studio Codeなどのテキストエディタで、保存フォルダ内のindex.htmlを開きます。

  4. 編集を始める前に、現在の状態をGitでCommitしておきます。変更前の状態が記録されるため、後から差分を確認しやすくなります。

02

文字を変更する

まず、テンプレート内の入力案内を自分の研究室の情報へ置き換えます。

  1. エディタの検索機能で「入力してください」を検索します。ページタイトル、説明、研究室名、各セクションの入力箇所を見つけやすくなります。

  2. ページタイトルと説明、研究室名の日本語・英語表記を変更します。開始タグと終了タグの間にある文字だけを置き換えます。

    <span class="header-name-wrapp-ja">○○大学 △△研究室</span>

  3. 「［～を入力してください］」の部分と、NEWS、研究テーマ、モットー、メンバー、プロフィール、Contactなどの文章を確認済みの内容へ変更します。

  4. 入力後に、氏名、所属、研究内容、論文、受賞歴などが正しいか原資料と照合します。

タグは原則として消さない

<と>で囲まれたタグやclassは、表示や機能に使われています。不要な項目でも、範囲が分からないまま削除しないでください。

事実を確認して入力

実在しない研究内容、論文、受賞歴などを作らないでください。不要な項目は適当な情報で埋めず、公開前に掲載方法を確認します。

03

画像を変更する

画像ファイルを保存し、HTMLからそのファイルを読み込むように変更します。

  1. 使用する画像をリポジトリ内のassets/images/へ保存します。

  2. index.html内のsrcを、保存した画像のファイル名に合わせます。

    <img src="./assets/images/lab-photo.jpg" alt="研究室の活動風景" />

  3. altへ「研究室の活動風景」のような、画像内容の短い説明を書きます。

  4. index.htmlをブラウザで開き、画像が正しく表示されるか確認します。

ファイル名と掲載許可を確認

  • ファイル名の大文字と小文字は区別されます。
  • 日本語や空白を避け、lab-photo.jpgのような分かりやすい英数字を使います。
  • ファイル名を変えた場合は、HTML側のsrcも変更します。
  • 元画像と同じ名前でも、拡張子が変わればsrcの修正が必要です。
  • 人物、学生、大学ロゴなどは掲載許可を確認します。

04

各セクションを編集する

index.html内のSTARTとENDのコメントを目印に、編集する範囲を探します。

<!-- START 研究テーマ -->
...
<!-- END 研究テーマ -->

主なセクション

  • 研究テーマ
  • NEWS
  • 研究室のモットー
  • 研究室メンバー
  • プロフィール
  • 論文・研究発表
  • Contact

編集時の基本ルール

  • 見出しや本文は、既存の入力案内を確認済みの内容へ置き換えます。
  • 項目を増やす場合は、対応するli要素をひとまとまりで複製します。
  • コピーする範囲が分からない場合は無理に増やさず、Codexなどへ変更を依頼します。
  • ナビゲーション部分へリンクを直接書き足しません。テンプレートのナビゲーションは各セクションの情報から生成されます。

無料利用時の帰属表示

フッターのアカデメイア帰属表示は、削除、非表示、別URLへの変更を行わないでください。

05

ブラウザで確認する

公開前に、編集した内容と表示を自分の目で確認します。

  1. 編集したindex.htmlを保存します。

  2. 保存したindex.htmlをブラウザで開きます。

  3. 変更した文字や画像が意図どおり表示されるか確認します。

  4. PC幅とスマートフォン相当の幅で表示を確認します。

  5. 問題がなければ、GitHub DesktopでCommitとPushを行います。

公開前の確認事項

  • 文字化けしていない
  • 画像が表示されている
  • 不要なサンプル文言が残っていない
  • リンク先が正しい
  • 横スクロールや大きな表示崩れがない
  • 氏名、所属、論文、住所、メールアドレスなどが正しい
  • 未公開情報や個人情報が含まれていない

GitHubへ反映する

CommitとPushの詳しい操作は、GitHubで公開・更新するマニュアルを確認してください。
