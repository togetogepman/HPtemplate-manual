About

研究室ホームページ作成に特化したテンプレート

研究内容、NEWS、メンバー、プロフィール、論文・研究発表、Contactなど、研究室サイトに必要な主要セクションを備えています。予算と作業を抑えながら、確認済みの文章と写真を中心に研究活動を紹介できます。

HTMLを一つずつ直接書き換える代わりに、配布されるExcelへ情報を整理し、ローカルCodexがテンプレートへ反映します。AIが反映した内容は、公開前に必ず人が確認します。

Features

FEATURE 01

テンプレートは無料で利用できます。GitHub Pagesなどを使い、費用を抑えて公開できます。

研究テーマ、メンバー、論文・発表など、研究室HPでよく使う情報を整理して掲載できます。

所定のExcelと写真を準備し、一文の指示でローカルCodexへ初期カスタマイズを依頼します。

各サービスの提供内容、利用上限、利用条件は変更される場合があります。最新条件は各サービスの公式情報をご確認ください。

FAQ

よくある質問

無料で利用できますか？

テンプレートは無料で利用できます。GitHub Pagesにも無料利用枠がありますが、サービスの提供内容や条件は変更される場合があります。最新の公式情報をご確認ください。

プログラミング知識は必要ですか？

標準手順では、HTMLを直接編集せず、ExcelとローカルCodexを使います。AIの出力、掲載事実、表示結果を人が確認できることは必要です。

どのようなデザインですか？

青と白を基調に、研究内容、メンバー、論文・発表などを縦長のセクションで掲載する、落ち着いた研究室向けデザインです。完成サンプルで全体像を確認できます。

GitHub Pages以外でも利用できますか？

静的HTMLを公開できる他のサービスでも利用できます。ただし、設定、料金、利用条件はサービスごとに異なり、このマニュアルの検証対象はGitHub Pagesです。

独自ドメインを利用できますか？

GitHub Pagesでは独自ドメインを設定できます。ドメインの取得・維持費と設定方法は提供元の公式情報をご確認ください。

ライセンスと著作権表示はどうなっていますか？

無料利用時はテンプレート本体のライセンスとフッターの帰属表示に従ってください。最新条件はテンプレート本体のLICENSE.mdをご確認ください。

モバイル表示に対応していますか？

PCとスマートフォンに対応するレスポンシブ設計です。公開前と公開後に、両方の表示を確認してください。

テンプレート画像はそのまま使えますか？

テンプレート同梱画像は、テンプレート本体の利用条件と出典表示に従ってください。自分で追加する写真やロゴは、掲載権利を確認してください。

困った場合はどう伝えればよいですか？

「どの画面で」「何を押したら」「何と表示されたか」の3点と、省略していないエラー文をCodexまたはChatGPTへ伝えてください。原因を自分で推測する必要はありません。
