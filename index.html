テンプレートの紹介

  • 研究室ホームページ作成に特化

    研究内容、NEWS、メンバー、プロフィール、論文・研究発表、Contactなど、研究室サイトに必要な主要セクションを備えた静的HTMLテンプレートです。

    研究内容や写真を掲載し、研究活動を分かりやすく紹介できます。

  • ExcelとローカルCodexで反映

    HTMLを一つずつ直接書き換える代わりに、配布されるExcelへ情報を整理し、ローカルCodexでテンプレートへ反映します。反映後に内容と表示を確認してから公開します。

研究支援サービスを提供するアカデメイアが、研究者のWeb発信を支援するために無料公開しています。

3つの特徴

  • 無料で利用できるテンプレート

    テンプレートは無料で利用できます。GitHub Pagesを使って、費用を抑えて公開できます。

  • 研究室向けの構成

    研究テーマ、メンバー、論文・発表など、研究室HPでよく使う情報を整理して掲載できます。

  • 入力と反映を分離

    所定のExcelと写真を準備し、一文の指示でローカルCodexへ初期カスタマイズを依頼します。

利用方法

公開までの3段階

  1. 準備する

    GitHubと必要なアプリを用意し、Privateの自分用リポジトリを作ります。

  2. 入力・反映する

    input/laboratory-input.xlsxへ研究室情報を入力し、使用する画像をinput/images/へ保存します。用意された指示文をCodexへ貼り付け、HPへ反映します。

  3. 確認して公開する

    内容と表示を確認した後、リポジトリをPublicへ変更してGitHub Pagesで公開します。

FAQ

  • 無料で利用できますか？

    テンプレートは無料で利用できます。Codexなど外部サービスの利用条件は、ご自身の契約内容をご確認ください。

  • プログラミング知識は必要ですか？

    HTMLを直接編集する必要はありません。Excelへ情報を入力し、完成したHPの内容と表示を確認できれば利用できます。

  • どのようなデザインですか？

    完成サンプルで、PCとスマートフォンでのデザインを確認できます。

  • GitHub Pages以外でも利用できますか？

    静的HTMLを公開できる他サービスでも利用できますが、このマニュアルの検証対象はGitHub Pagesです。

  • 独自ドメインを利用できますか？

    GitHub Pagesでは独自ドメインを設定できます。取得費用と設定方法は提供元の公式情報をご確認ください。

  • ライセンスと著作権表示はどうなっていますか？

    無料利用時はテンプレート本体のライセンスとフッターの帰属表示に従ってください。

  • モバイル表示に対応していますか？

    PCとスマートフォンに対応しています。公開前と公開後に両方の表示を確認してください。

  • テンプレート画像はそのまま使えますか？

    同梱画像はテンプレート本体の利用条件と出典表示に従ってください。追加する写真やロゴは掲載権利を確認してください。

  • 困った場合はどう伝えればよいですか？

    「どの画面で」「何を押したら」「何と表示されたか」と、省略していないエラー文をCodexまたはChatGPTへ伝えてください。

このテンプレートで足りない場合

このテンプレートは、研究室HPを手軽に作成・公開するためのものです。複数人での更新、多言語対応、研究プロジェクト専用サイト、研究用Webツールなど、テンプレートだけでは対応しにくい用途は、アカデメイアが個別に設計・開発します。
