最終確認をしてHPを公開する

まず一般公開されない設定（Private）のまま、公開してよい内容だけが含まれていることを確認します。その後、GitHub上のファイルを誰でも見られる状態にし、GitHub Pagesで通常のWebサイトとして公開します。

公開は2段階です

  1. リポジトリをPublicにする
    GitHub上のHPファイルを誰でも見られる状態にします。
  2. GitHub Pagesを有効にする
    HPファイルを通常のWebサイトとして表示します。

このページが終わると

  • 公開してよい内容だけがGitHub上にある
  • 自分専用の作業場所（リポジトリ）がPublicになっている
  • GitHub Pagesの公開URLを開ける
  • 公開されたHPをPCとスマートフォンで確認できている

このページで行うこと

  • 公開してよい内容か確認する
  • ファイルを誰でも見られる状態にする
  • 一般公開を確認する
  • Webサイト公開を設定する
  • 公開されたHPを確認する

Privateのまま公開前の最終確認をする

まだ一般公開されていない状態で、研究代表者または公開責任者が次の4分類を確認します。すべて確認できた後にだけPublicへ変更します。

内容

  • 研究内容
  • 氏名、所属、肩書
  • 論文・業績
  • 問い合わせ先

公開許可

  • 写真とロゴの掲載権利
  • 個人情報
  • 未公開研究情報

GitHub上のファイル

  • Excel原本が含まれていない
  • 写真原本や確認用メモが含まれていない
  • パスワードやAPIキーが含まれていない
  • 公開後に誰でも見られる変更履歴を確認した

表示

  • PC
  • スマートフォン
  • 画像
  • リンク

判断は人が行います

事実関係、掲載許可、画像の権利、未公開情報の有無は、人が原資料と関係者への確認に基づいて判断してください。

リポジトリをPublicへ変更する

Public化する前の注意

Publicへ変更すると、リポジトリ内のファイルと変更履歴を誰でも閲覧できるようになります。公開してよい内容だけが含まれていることを確認してから変更してください。

Danger Zoneについて

「Danger Zone」という名前ですが、ここではリポジトリの公開範囲を変更するために使用します。削除操作は行わず、削除ボタンは押さないでください。

  1. GitHub上の自分専用リポジトリでSettingsを開きます。

  2. Generalページ下部のDanger Zoneへ進みます。

  3. Change repository visibilityで公開範囲の変更を開始します。

  4. Publicを選び、GitHubが表示する影響と対象リポジトリ名を確認してから確定します。

GitHub公式：リポジトリの可視性を設定する

リポジトリがPublicになったことを確認する

  1. リポジトリにPublicと表示されていることを確認します。

  2. シークレットウィンドウを開きます。

  3. リポジトリURLを開き、GitHubへサインインしていなくても閲覧できることを確認します。

GitHub PagesでWebサイト公開を設定する

HPの公開元となる作業系列（branch）と公開元フォルダは、このテンプレートの標準値を選びます。

  1. GitHub上の自分専用リポジトリでSettingsを開き、左側のPagesを選びます。

  2. Build and deploymentのSourceでDeploy from a branchを選びます。

  3. Branchはmainを選びます。

  4. Folderは/(root)を選び、Saveを押します。

GitHub公式：GitHub Pagesサイトの発行ソースを構成する

公開されたHPを確認する

Pagesの設定だけでは完了ではありません。公開URLでHPが表示されることを確認します。

  1. Settings → Pagesを開き、公開URLまたはVisit siteが表示されることを確認します。

  2. シークレットウィンドウで公開URLを開きます。

  3. 研究室HPのトップページが表示されることを確認します。

  4. PCとスマートフォンの両方で、画像とリンクを確認します。

設定保存直後に表示されない場合

反映に時間がかかる場合があります。GitHubの画面にエラーが表示されていないか確認し、少し待ってから公開URLを再読み込みしてください。

公開完了

シークレットウィンドウで公開URLを開き、PCとスマートフォンでHP、画像、リンクを確認できたら公開完了です。
