Step 3

人が確認し、Public化とPages公開を行う

リポジトリがPrivateのうちに内容、権利、表示、GitHub上のファイルを人が最終確認します。確認完了後にPublicへ変更し、一般公開を確認してから、別工程としてGitHub Pagesを設定します。

このページの完了条件

  • リポジトリがPublicである
  • シークレットウィンドウからリポジトリを閲覧できる
  • GitHub Pagesの公開URLが表示されている
  • シークレットウィンドウからPages URLを開ける
  • 公開URLでPC・スマートフォン表示を確認した
  • 画像とリンクに問題がない

このページで行うこと

  • 公開前の最終確認
  • Publicへ変更
  • Publicを確認
  • GitHub Pages
  • Pages公開を確認

Privateのまま公開前の最終確認をする

この確認中、リポジトリはまだPrivateで、一般には公開されていません。研究代表者または公開責任者が次のすべてを確認し、完了した後にだけPublic化へ進みます。

  • 掲載内容が正しい
  • 連絡先が正しい
  • 写真・ロゴの権利を確認した
  • 未公開情報が含まれていない
  • PCとスマートフォンで表示を確認した
  • Excel原本や写真原本がGitHub上に含まれていない
  • 不要なローカルファイルがGitHub上に含まれていない
  • Codexが報告した未確認事項を解消した

判断をAIへ任せない

事実関係、掲載許可、画像の権利、未公開情報の有無は、人が原資料と関係者への確認に基づいて判断してください。GitHub上のファイルだけでなく、公開後に誰でも閲覧できる変更履歴も確認します。

リポジトリをPublicへ変更する

Public化する前の注意

Publicへ変更すると、リポジトリ内のファイルと変更履歴を誰でも閲覧できるようになります。公開してよい内容だけが含まれていることを確認してから変更してください。

  1. GitHub上の自分用リポジトリでSettingsを開きます。

  2. Generalページ下部のDanger Zoneへ進みます。

  3. Change repository visibilityで可視性の変更を開始します。

  4. Publicを選び、GitHubが表示する影響と対象リポジトリ名を確認してから確定します。

GitHub公式：リポジトリの可視性を設定する

リポジトリがPublicになったことを確認する

  1. GitHub上でリポジトリの表示がPublicになっていることを確認します。

  2. リポジトリURLをコピーします。

  3. GitHubからログアウトした状態、またはシークレットウィンドウでリポジトリURLを開きます。

  4. GitHubへサインインしていなくてもリポジトリを閲覧できることを確認します。

サインイン中の表示だけでは不十分です

所有者としてサインイン中のブラウザで見えるだけでは、一般公開の確認になりません。必ずログアウト状態またはシークレットウィンドウでも確認します。

Public化後にGitHub Pagesを設定する

リポジトリのPublic化とGitHub Pages公開は別の操作です。リポジトリがPublicになったことを外部から確認した後に、Pagesを設定します。

  1. GitHub上の自分用リポジトリでSettingsを開き、左側のPagesを選びます。

  2. Build and deploymentのSourceでDeploy from a branchを選びます。

  3. 公開対象のbranchを選びます。分からない場合は推測せず、テンプレート本体の案内またはリポジトリ管理者へ確認します。

  4. 公開元フォルダに/(root)を選び、Saveを押します。

GitHub公式：GitHub Pagesサイトの発行ソースを構成する

GitHub Pagesが公開されたことを確認する

  1. Settings → Pagesを開きます。

  2. GitHubが表示する公開URLまたはVisit siteを確認します。

  3. 公開URLを新しいタブで開き、トップページが表示されることを確認します。

  4. ログアウト状態またはシークレットウィンドウでも公開URLを開きます。

  5. PCとスマートフォンの両方で表示を確認します。

  6. 画像、CSS、JavaScript、内部リンク、外部リンクを確認します。

設定保存直後に表示されない場合

反映に時間がかかる場合があります。GitHubの画面にエラーが表示されていないか確認し、少し待ってから公開URLを再読み込みしてください。URLやbranch設定を推測で変更しないでください。

公開完了条件

リポジトリがPublicでシークレットウィンドウから閲覧でき、GitHub Pagesの公開URLが表示され、そのURLもシークレットウィンドウから開けることが必要です。さらに公開URLをPC・スマートフォンで確認し、画像とリンクに問題がない状態を公開完了とします。
