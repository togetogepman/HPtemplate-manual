Steps 1–2

利用環境とテンプレートを準備する

必要なアカウントとアプリを用意し、自分用のテンプレートをパソコンへcloneして、サイト編集を始められる状態にします。

このページで行うこと

  1. Step 1：利用環境を準備する
  2. Step 2：自分用のテンプレートを用意する

STEP 1

利用環境を準備する

GitHub、GitHub Desktop、Windows版ChatGPTデスクトップアプリへサインインします。この段階では、まだCodexへ切り替えません。

  1. GitHubでアカウントを作成します。GitHubは、ホームページのファイルと変更履歴をインターネット上で管理するサービスです。

  2. GitHub Desktop公式ダウンロードページから、Windows版GitHub Desktopをインストールします。

  3. GitHub Desktopを開き、ブラウザのGitHubと同じGitHubアカウントでサインインします。

  4. OpenAI公式のWindows版案内を確認し、ChatGPTデスクトップアプリをインストールします。

  5. ChatGPTデスクトップアプリを起動し、普段使用するChatGPTアカウントでサインインします。

完了条件

GitHub、GitHub Desktop、ChatGPTデスクトップアプリへサインインできれば完了です。

STEP 2

自分用のテンプレートを用意する

配布用テンプレートから自分のリポジトリを作り、GitHub Desktopでパソコンへcloneします。

リモートリポジトリ
GitHub上に保存されているホームページのファイルと変更履歴です。
ローカルリポジトリ
GitHub Desktopでcloneして、パソコン上へ保存した作業用フォルダです。

  1. academeia/hp_templateをブラウザで開きます。

  2. Use this templateを押し、新しいリポジトリを作成する項目を選びます。

  3. 所有者、リポジトリ名、公開範囲を確認します。公開してよい内容であることを確認してPublicを選び、作成します。

  4. 作成した自分のリポジトリをGitHub Desktopでcloneします。対象とパソコン上の保存先を選び、Cloneを押します。

  5. GitHub Desktop左上のリポジトリ一覧から、いま作成した自分のリポジトリを選びます。

  6. RepositoryメニューからShow in Explorerを選び、保存場所を開きます。

  7. 開いたフォルダに、index.html、sample.html、prompts、assets、README.mdが含まれていることを確認します。

公開できない情報を入れない

Publicリポジトリの内容は誰でも確認できます。パスワード、個人情報、未公開資料を入れないでください。

完了条件

自分用のリポジトリがパソコンへcloneされ、保存フォルダを確認できれば準備完了です。
