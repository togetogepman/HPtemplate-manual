HPを作るための準備をする

必要なサービスへ登録し、研究室HPテンプレートの自分専用コピーをGitHubとパソコンに用意します。最後に、そのフォルダをCodexで開きます。

このページが終わると

  • 必要なサービスへサインインできる
  • テンプレートの自分専用コピーがGitHub上にある
  • そのコピーが一般公開されない設定（Private）になっている
  • 自分専用コピーがパソコンにも保存されている
  • Codexで研究室HPのフォルダを開ける

このページで行うこと

  • 3つの道具を準備する
  • 自分専用コピーを作る
  • パソコンへ保存する
  • HPフォルダをCodexで開く

アカウントとアプリを準備する

公開までに使う3つの道具を準備します。

GitHub
HPのファイルをインターネット上に保管します。公開時はGitHub Pagesの機能を使います。
GitHub Desktop
GitHub上のファイルをパソコンへ保存し、Codexの変更をGitHubへ戻します。
ChatGPT / Codex
パソコン上のHPファイルを編集します。

  1. GitHubでアカウントを作り、メールアドレスの確認まで終えます。

  2. GitHub Desktopをインストールし、同じGitHubアカウントでサインインします。

  3. OpenAI公式：ChatGPTデスクトップアプリの導入案内を確認し、ChatGPTデスクトップアプリをインストールしてサインインします。

  4. アプリ内でCodexを開けることを確認します。利用方法やプランごとの上限は、OpenAI公式：ChatGPTプランでCodexを使うを確認してください。

テンプレートの自分専用コピーを作る

配布元を直接変更せず、自分のGitHubアカウントに作業用のコピーを作ります。このGitHub上の作業場所を「リポジトリ」と呼びます。一般公開されない設定（Private）にし、内容確認後に公開ページで誰でも見られる設定（Public）へ変更します。

  1. 研究室HPテンプレート本体を開きます。

  2. Use this templateを押し、Create a new repositoryを選びます。

  3. Ownerが自分のアカウントになっていることを確認します。

  4. Repository nameには、半角英数字とハイフンで「研究室名-lab」のように入力します。例：sample-lab、togo-lab。同じ名前が使われている場合は、sample-lab-2のように末尾へ数字を付けます。

  5. VisibilityでPrivateを選びます。

  6. 入力内容とPrivateの選択を確認し、自分専用コピーを作成します。

  7. 作成後、自分のアカウント名とリポジトリ名が画面上部に表示され、表示がPrivateであることを確認します。

Privateでも保存してはいけない情報

Privateは一般公開を防ぐ設定ですが、機密情報の保管場所ではありません。パスワード、APIキー、認証情報、公開許可前の不要な個人情報はGitHubへ保存しないでください。

GitHubの自分専用コピーをパソコンへ保存する

GitHub上の自分専用コピーをパソコンへ保存します。この操作を「clone」と呼びます。

  1. GitHub DesktopでFile → Clone repositoryを開き、自分専用コピーを選びます。

  2. Local PathはGitHub Desktopが最初に表示した保存場所をそのまま使用して構いません。後でCodexから開くため、画面に表示された場所だけ確認してCloneを押します。

  3. GitHub Desktop左上に自分専用コピーの名前が表示され、Show in Explorer（Windows）またはShow in Finder（macOS）からフォルダを開ければ完了です。

保存したHPフォルダをCodexで開く

  1. ChatGPTデスクトップアプリでCodexを開きます。

  2. フォルダを開く操作から、先ほどGitHub Desktopで保存したフォルダを選びます。

  3. Codexの画面に、研究室HPのフォルダ名とファイル一覧が表示されていることを確認します。

成功状態

研究室HPのフォルダ名とファイル一覧がCodexに表示されていれば、この工程は完了です。
