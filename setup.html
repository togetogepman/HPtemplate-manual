Step 1

利用環境と自分用リポジトリを準備する

必要なアカウントとアプリを用意し、テンプレートから自分用リポジトリを作り、パソコンへcloneしてローカルCodexで開きます。

このページの完了条件

  • GitHubアカウントがある
  • ChatGPTデスクトップアプリへサインインできる
  • GitHub Desktopへサインインできる
  • テンプレートから作った自分用リポジトリがある
  • GitHub Desktopでclone済みである
  • ローカルCodexでclone先を開ける

このページで行うこと

  • アカウントとアプリ
  • 自分用リポジトリ
  • clone
  • Codexで開く

アカウントとアプリを準備する

このマニュアルでは、GitHubでファイルを保管し、GitHub Desktopでパソコンと同期し、ChatGPTデスクトップアプリ内のローカルCodexで変更します。

GitHub
HPのファイルと変更履歴をインターネット上で保管します。
GitHub Desktop
GitHub上のリポジトリをパソコンへcloneし、変更の同期に使います。
ローカルCodex
cloneしたフォルダを読み、ファイル変更と表示確認を行います。

  1. GitHubでアカウントを作り、メールアドレスの確認まで終えます。

  2. GitHub Desktopをインストールし、同じGitHubアカウントでサインインします。

  3. OpenAI公式のデスクトップアプリ案内を確認し、ChatGPTデスクトップアプリをインストールしてサインインします。

  4. アプリ内でCodexを開けることを確認します。利用可否や上限はプラン等で変わるため、表示されない場合はOpenAI公式情報を確認します。

標準ルートを一本にします

ChatGPTとGitHubの接続やCodexクラウドは、この初期カスタマイズには使いません。通常のChatGPTは、文章整理やエラーの説明が必要なときだけ任意で使えます。

テンプレートから自分用リポジトリを作る

配布元を直接変更せず、自分のGitHubアカウントに作業用コピーを作ります。

  1. 研究室HPテンプレート本体を開きます。

  2. Use this templateを押し、Create a new repositoryを選びます。

  3. Owner、Repository name、公開範囲を確認して作成します。GitHub Pagesの無料利用枠で公開する場合は、現在の条件をGitHub公式情報で確認してください。

  4. 作成後、自分のアカウント名と指定したリポジトリ名が画面上部に表示されれば完了です。

公開できない情報を入れない

Publicリポジトリは誰でも閲覧できます。パスワード、APIキー、個人情報、未公開資料を保存しないでください。

GitHub Desktopでcloneする

GitHub上の自分用リポジトリを、編集に使うパソコンへコピーします。

  1. GitHub DesktopでFile → Clone repositoryを開き、自分用リポジトリを選びます。

  2. Local Pathで保存場所を確認し、Cloneを押します。

  3. GitHub Desktop左上に自分用リポジトリ名が表示され、Show in Explorerからフォルダを開ければ完了です。

ローカルCodexでclone先を開く

  1. ChatGPTデスクトップアプリでCodexを開きます。

  2. フォルダを開く操作から、GitHub DesktopのLocal Pathで確認したclone先を選びます。

  3. Codex上にリポジトリ名とファイル一覧が表示され、ルートのREADME.mdやAGENTS.mdを参照できることを確認します。

成功状態

配布元ではなく、自分用リポジトリのローカルフォルダをCodexで開けていれば、この工程は完了です。
